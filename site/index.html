Interactive cards from any Agent, checked before anyone sees them

Your Agent writes a JSON component tree. Your host validates and repairs it, commits it, and a browser renders forms, choices, tables, links and previews. What the user does comes back as structured events. Any model, any backend language.

Start building

One package covers each part of the cycle. Pick the part you own; every snippet below runs against @haowei2000/intelligence-ui 0.3.

Agent backend in Node

Tell the model what it may build, then publish only what validates.

import { createContract } from '@haowei2000/intelligence-ui/protocol';
import { instructions, fix, repairFeedback } from '@haowei2000/intelligence-ui/agent';

const contract = createContract({
  actions: [{ id: 'submit-plan', input: 'form' }]
});
const system = `${yourPrompt}\n\n${instructions(contract)}`;

const result = fix(modelOutputText, { contract });
if (result.valid) await publish(result.document);
else await askModelAgain(repairFeedback(result));

import json, urllib.request

body = {"document": candidate, "baseRevision": 0}

    data=json.dumps(body).encode(), method="PUT",
    headers={"Authorization": f"Bearer {AGENT_TOKEN}",
             "Content-Type": "application/json"})

Host service

Run it standalone, or mount it in your Node server with your own sign-in.

npx @haowei2000/intelligence-ui serve --config config.json
import { createUIService } from '@haowei2000/intelligence-ui/node';

const service = createUIService({
  contract,
  authenticate: req => sessions.principalFor(req),
  onEvent: async event => { await queue.enqueue(event); return { status: 'accepted' }; }
});
// in your server: if (!(await service.handle(req, res))) next();

How it works

  1. DiscoverThe Agent reads the host's contract: components, registered actions, limits and URL policy.
  2. Generate and repairValidation finds every problem at once; safe fixes apply automatically, the rest come back as precise diagnostics.
  3. PublishOnly valid documents are committed and delivered. Rejected candidates never reach the user.
  4. InteractTyping and choosing run locally. Submissions return as validated events; new revisions keep what the user entered.

What's included

Protocol

17 components, JSON Schema, semantic rules and conformance cases any language can implement.

Validation and Autofix

Stable diagnostic codes with JSON Pointer paths. Fixes never invent ids, actions or data.

Browser and React runtime

Shadow DOM rendering with no eval and no HTML from the model. Works under a strict CSP.

Delivery service

HTTP and streaming delivery, server-side event checks, deduplication and an event log with cursors.

MCP and CLI

Five MCP tools over stdio or HTTP, and validate, fix and contract commands for CI.

Agent Skill and examples

A portable Skill, plus TypeScript and Python Agents that complete the full cycle with a separate frontend.
